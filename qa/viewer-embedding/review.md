# ビューアー連携のコードレビューと改善記録

実施日：2026年10月4日。対象は共通ビューアーとその取得層、埋め込み入口、文書処理とナレッジAPIの閲覧経路、閲覧仲介、MCP、Open WebUI Tool、および通常画面の翻訳・印刷との境界である。既存の別作業の変更は保持した。

認証・版・失効、入力と応答の検証、資料資産の配信、画面状態の順にレビューした。再現テストを加えて修正し、修正箇所と呼び出し元を再レビューした。最終確認では、この範囲に追加の修正が必要な問題は見つからなかった。

## 修正した問題

| 優先度 | 問題と発生条件 | 改善 | 主な確認 |
| --- | --- | --- | --- |
| P1 | 閲覧の承認中、manifest取得後に利用者のscopeが変わると、古い確認結果を新しい権限のセッションとして登録する | 承認前の権限の識別値を保持し、取得後にも比較して拒否する | test_policy_change_after_manifest_does_not_grant_a_session |
| P1 | MCPの認証後に同じ資格情報を別利用者へ付け替えると、以前の利用者としてToolを実行・返答できる | 実行前後に資格情報と利用者の両方を再確認する | test_mcp_revalidates_the_same_token_owner_before_returning（実行前・途中） |
| P1 | Open WebUIの引用作成中に資料の削除、版変更、閲覧権限の取り消しを検知しても、検索済みの本文を返し続ける | 認証と版の失効は返答を止める。プレビュー障害による代替表示と区別する | test_search_stops_before_emitting_stale_evidence_when_preview_detects_revocation（5種類） |
| P2 | 閲覧仲介の応答サイズ制限が全件受信後にしか働かず、大きな応答をメモリーへ読み込む | ストリームを読みながら制限し、超過後のチャンクを受信しない | test_api_response_limit_stops_consuming_an_oversized_stream |
| P2 | Unicodeの接続コードや認証ヘッダーが比較処理で例外になる | 接続コードは8桁の16進数だけを許可し、認証情報はバイト列で比較する | 無効コード・非ASCIIヘッダーの試験 |
| P2 | 不正なJSON、manifest、Base64、Content-Typeが内部例外や不正なHTTP応答になる | 型と形式を確認し、制御した502/503応答にする | malformed_upstream_metadata / malformed_upstream_asset |
| P2 | URLエンコードされたセッションやチャレンジの識別子がアクセスログの伏せ字処理を抜ける | 識別子を含むパス区間全体を伏せる | ログの通常形・エンコード形の試験 |
| P2 | HTML内のSVG画像のxlink:hrefが元の/files/を参照し、埋め込みで取得できない | SVGの参照属性も閲覧セッションの取得経路に変換する。表示文字は変えない | test_viewer_rewrites_svg_links_without_inserting_tokens_in_text |
| P2 | プレビュー要求の通信がタイムアウトすると、検索結果と引用も失敗する。同じ参照を検索チャンクごとに取得する | 通信障害をプレビュー未表示の検索結果として扱い、同じ参照・位置の解決は1回にする | preview_timeout_preserves_search_and_citations_and_is_not_retried_per_chunk |
| P2 | 翻訳ダイアログが更新前の情報で初期選択を決める。また翻訳・印刷がイベントのDOM値を後で参照する | 更新後の単位を選び、イベント発生時の値を保持して状態を更新する | Translation.test.tsxと既存Braveでの操作確認 |

最初に追加した閲覧仲介の再現テストは修正前に8件失敗し、修正後に成功した。引用の失効に関する5件も修正前に失敗し、修正後に成功した。翻訳の試験は、初回の情報が空で再取得時に単位が揃う場合、同じ描画の更新に含まれる複数の選択操作、未選択時の拒否、選択した単位だけの送信を確認する。

ブラウザーは既存のBraveプロファイルを拡張経由で操作した。隔離した通常画面の試験サーバーを使い、翻訳の選択を3回往復して保持されること、未選択時の拒否、選択範囲の再翻訳と訳文表示を確認した。印刷ではレター・横向き・20mmの設定と、生成されたページ寸法・余白、印刷可能になること、閉じた後のフォーカス復帰を確認した。外部LLMやプリンターには送信していない。

画面はreview-translation.pngとreview-print.png、実装と試験のハッシュはreview.jsonに保存した。試験タブを閉じ、試験サーバーも終了した。別のブラウザーやプロファイルは起動していない。

前回の6形式・実Open WebUIの接続検証と66件の通常画面試験はverification.mdに残す。今回はその一括ブラウザー試験を再実行していない。前回の自動選択操作1件の失敗を、今回の全件成功に含めない。今回の選択処理の修正は、新しい回帰テストと既存プロファイルでの実操作で検証した。
