# 利用条件と性能予算

2026年10月4日に、測定前の利用条件として確定した値です。合格済みの実測値ではありません。対象外の規模は保証しません。

| 項目 | 確定値 |
| --- | --- |
| ローカル画面 | 個人利用。待ち受けはループバック。認証なしで広域公開しない |
| 外部API | 資格情報と資料範囲を制御する。保存領域は `.knowledge-api` で、Wiki正本とは別 |
| 処理 | 単一のAPI所有者と処理worker。SQLite。GPUなしを基準 |
| Linux配布の目安 | CPU 4コア、メモリ16 GiB |
| ローカル測定 | 開発に使うMacでも別に測る |
| データ規模 | 100文書および1,000文書、検索チャンク合計10,000、Wiki 100記事、PDF最大100ページ |
| 意味索引 | 通常は1,024次元。APIが受け付ける8,192次元は同じ性能を保証しない |
| 同時実行 | API検索8件まで。9件目は拒否。アップロードは3件まで |
| 全文検索 | 索引作成済み10,000チャンクで p95 300 ms以内。同期を含む待ち時間 |
| キャッシュ済みHybrid | 同じ規模で p95 2秒以内 |
| 親文脈 | UI既定4,000トークンで p95 500 ms以内。API上限16,000は別測定 |
| 8同時検索 | 全文 p95 1秒以内。時間切れと取消のあと通常処理へ戻る |
| 画面 | 温かい状態の p95 1秒、冷たい状態の p95 2秒 |
| メモリ | 宣言した通常負荷でAPI、Python、変換子プロセスのRSS合計8 GiB以内 |
| 外部要求 | 変更がない再索引の追加embeddingは0。同じ条件の再取得は0 |
| 保持 | 再生成キャッシュ14日、サムネイル30日。原本・Wiki正本・使用中の成果物は自動削除しない |
| Azure待ち | 最低15秒とRetry-Afterはローカルの2秒予算に混ぜない |

変換と印刷の時間上限は、代表入力の初回測定が終わるまで未定です。未定のまま性能予算の合格にはしません。

2026年10月4日に、このMacの単一Pythonプロセスで合成Wikiを測りました。100文書・10,000チャンク・30回です。全文検索のp95は128次元で55ms、1,024次元で66msでした。キャッシュ済みHybridのp95は128次元で283ms、1,024次元で1.25秒、最大RSSは1,024次元で約943 MiBでした。外部要求は0です。記録は `qa/technical-quality/search-bench.json` と `search-bench-1024.json` です。これはAPI同時実行、画面、変換、印刷、1,000文書の実変換を含みません。
