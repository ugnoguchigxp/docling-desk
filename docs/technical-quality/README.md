目標は、前回と同じ評価基準で**技術品質の正式評価が80点を超えること**です。全30項目の目標を満たす条件付き試算は**83.8点**。実装と検証が完了するまでは到達済みと扱いません。今回行ったのは現状確認と計画書の作成であり、製品コードの改善実装は含みません。

## 評価範囲と守る条件

評価基準は`review-software-project`のrubric 1.1.0、technical、balanced、deepを固定します。10分野30項目をすべて対象とし、未確認項目を採点対象外へ移して点数を上げません。プロジェクトの事業性・需要・回答モデル自体の優劣は、この技術品質の点数とは別です。

利用条件は、個人のローカル利用と、資格情報・対象資料の範囲を制御する外部ナレッジAPIです。現在のComposeはホストのループバックへ公開し、処理サービスのホストポートは公開しません。ローカル画面を認証なしで広くネットワークへ公開する構成を、本計画の合格範囲へ追加しません。公開範囲を変更する場合は、その実際の構成を追加評価します。

以下の設計上の利点は維持します。

- 原本、抽出成果物、検索チャンク、出典の関係を追えること。再抽出・索引更新・印刷で原本を書き換えないこと。
- SQLiteと単一所有者・処理ジョブを使う現在の構成。測定前に別のデータベースや分散処理を導入しないこと。
- Wikiの正本ファイル・manifestと検索用SQLiteを、外部APIの `.knowledge-api` とは独立した保存領域として扱うこと。2026年10月5日の保存構成変更は[保存構成と移行](../content-storage.md)を参照。
- ローカルOCRとAzure OCRの選択が明示的であること。送信済みか不明なOCR要求を自動で再送しないこと。
- 意味検索未設定でも、ローカルWiki閲覧と全文検索を使えること。

順序はG0→G1→G2→G3→G4です。Q05の依存棚卸しやQ08のCI整備はG0後に先行できますが、最終試験はG1の実装を含む同一版で実行します。工程を飛ばして試算点を正式評価へ移しません。

最初に取り組むのは**Q01の版固定、Q03の実プロセス障害試験、Q04の新しいWiki・印刷を含む信頼境界の確認**です。前回のAPI修正を作り直すより、修正が新機能との組合せでも維持されることを先に確かめます。

30項目がすべて評価値3なら75点です。代表的な例外に対応するだけでは80点を超えません。下表の9項目では、境界・失敗・別の説明を実行や独立した観測で確かめ、評価値4の条件を満たすことを目指します。残る21項目は評価値3を目指します。

丸める前の合計は83.75点、表示は83.8点です。分野評点の表示値から再計算せず、各項目の整数値と固定重みから計算します。9項目の評価値4がすべて3に留まれば75点です。したがって実装量やテスト件数を増やすだけでは達成としません。

80点超え自体が完了の条件であり、83.8点への一致は必須ではありません。新しい実績台帳が80点を超え、後述の品質条件を満たせば完了できます。反対に、点数だけ超えても確認済みCritical・High問題や未調査の重大な疑いが残る場合は完了にしません。

## 担当と見積もりの扱い

実装担当はPython・API・画面・配布の各責任範囲を持ち、検証担当は入力と保存状態を別経路から観測します。リリース担当はモデル・依存・権利の台帳と配布成果物を確認します。氏名や人数は未定です。1人で進める場合も、修正の実装と反証試験を別の手順として記録します。同じ人の確認を独立した第三者レビューとは呼びません。

実装計画のS・M・Lは変更範囲の比較です。Sは既存チェックや文書への局所追加、Mは複数の関連モジュールと結合試験、Lは複数プロセス・保存領域・配布環境をまたぐ作業を意味します。日数の見積もりではありません。G0で現状との差分を確認してから担当と実施日を決めます。

## 終了の判断

- 固定した新しい版の30項目を、実際の根拠で評価済みにする。証拠充足率100%、適用除外による重み変更なし。
- 正式な技術品質スコアが厳密に80点を超える。ExpectedではなくRe-evaluatedの台帳と計算結果を残す。
- 確認済みCritical・High問題を解消し、重大な疑いの調査を終える。残る軽微な制限は利用条件とともに記載する。
- オフラインの回帰試験、実HTTP、Linuxの6形式変換、新機能のブラウザー試験、復旧・性能・配布の確認が同じ対象版で成立する。
- 更新後の運用手順と既知の制限を別の担当者が追試できる形で保存する。

いずれかが未達なら、Q09で不足する項目と最小の追加作業を計画へ戻します。評価値の引き上げを先に決めて終了しません。
