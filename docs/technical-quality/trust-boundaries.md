# 信頼境界

ローカル画面と外部APIは別の境界です。

| 境界 | 信頼するもの | 信頼しないもの |
| --- | --- | --- |
| ローカル画面 | ループバックの操作者 | 資料本文、Wiki本文、抽出HTML、モデル出力 |
| 外部API | 署名済み資格情報と、そのcollection、project、region | 他範囲の本文、保存済み検索、期限切れの資格 |
| 処理worker | 共有volume上のIDとSHA-256が一致する原本 | symlink、volume外のパス、資料内の命令 |
| OCR | 明示したprovider設定と、受付が確認できたoperation | 受付不明の自動再送、削除済みrunのcallback |
| 印刷 | 同一生成元のページ画像と受動化した文字 | script、イベント属性、外部画像、`javascript:`、iframe、meta refresh |
| Codex接続 | 設定されたコマンド範囲と返答スキーマ | 資料中の「ツールを使え」という文 |

設定の欠落を、より広い権限へ読み替えません。HostとOriginが許可リストに無いローカル操作は拒否します。APIの処理ポートはComposeで公開しません。

試験の標準はfake providerと合成データです。キー、署名、本文、元ファイル名をログ、エラー、ブラウザ保存へ残していません。実Azureへ送る試験は別枠で、このオフライン手順には含めません。
