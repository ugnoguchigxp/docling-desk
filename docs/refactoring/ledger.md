## 更新手順

1. 着手時に「状態」を進行中にし、「担当と対象版」へ担当・commit・ソース識別値を書く。
2. 変更ごとに「契約と差分」へ維持する契約と意図した変更、更新した契約文書を書く。
3. 検証後に「検証証拠」へコマンド・対象版・結果・not_runを書く。成功件数だけで完了にしない。
4. 受入条件と切り戻しを確認できたときだけ「完了」にする。取消後公開・認可逸脱・データ損失・復元不能が出た項目は「阻害あり」にし、依存作業を止める。
