# 資料一覧と画像ライブラリー

2026-10-16。資料一覧の表示切替・画像検索・画像詳細とMarkdownコピーの実装。画像生成やMD投稿処理は対象外。

連携の正本は [画像リソース連携仕様 v1](../../media-resource-contract.md)。[Markdown記述例](example-article.md) のハッシュは架空で、実在画像を指さない。

## 画面

- 上部の「資料一覧」タイトルは省略。保存先と表示対象・リスト／ギャラリーの切替を同じ行に小さくまとめ、一覧の表示領域を確保する。狭い幅では折り返す。

- 「すべての資料」は現在フォルダーの資料を表示。リスト／ギャラリーを切り替え、選択をブラウザー内でフォルダーごとに記憶する。URL指定を優先する。
- 「画像を探す」は全フォルダーの画像をサムネイル表示。名前・原本名・説明・タグで検索し、保存先と配下、形式、並べ替えで絞り込む。
- ギャラリーでは画像全体を表示。PDF・PowerPointは既存の表紙サムネイル、未生成・非対応形式は形式表示を使う。画像生成機能は設けない。
- 画像を開くと、周囲に小さな余白を残す大きなモーダルを表示。左に画像、右に属性。常設の詳細パネルは置かない。
- 右上のコピー欄はMarkdownテキストとコピーアイコンだけ。挿入ボタン、大型のコピーフッター、記事への直接送信は設けない。
- 編集項目は表示名、説明、タグ、代替テキスト、出典URL・表記。原本名、保存先、形式、寸法、容量は読み取り専用。属性は明示的な保存で更新する。
- 狭い幅では画像→属性の順に縦積み。Escape・閉じるで一覧へ戻り、元の画像ボタンへフォーカスを戻す。

## 既存機構との接続

原本、Job、配置、ファイル操作、表示用キャッシュを既存の資料機構へ接続する。画像アップロードは検証・保存とサムネイル生成まで完了してから成功を返し、文書抽出やOCRの待ち行列を占有しない。サムネイルは原画像に付随する内部キャッシュで、資料一覧への別登録は行わない。既存画像やキャッシュ消失時は取得時に再生成する。

実装時点で別担当のWikiに不変画像URLとPlate表示が存在したため、独自URIを追加せず、その画像URLをコピーする。Markdown記法だけで別タブへ引き渡せる。Wiki編集・投稿コードは変更しない。

コピー先を壊さないため、Wiki画像の不変原本は資料一覧の登録削除後も保持する。既存Wiki画像の保持方式に従う。未使用画像の自動削除や記事の参照管理の再設計は行わない。

## 検証と完了条件

着手時の関連検証はPython47件、React23件が成功。画像保存・整合性・属性競合、検索、移動・コピー・削除、キャッシュ、コピー記法を部分検証し、画面の属性保存・コピーを結合検証する。最後に実ブラウザーで画像追加→検索→詳細→コピー→別タブのMD表示を確認する。

完了条件は関連Python/React検証、型確認・lint、ブラウザー通し検証、ビルド・静的書き出し、差分点検。別担当のMD編集・投稿処理の不具合を見つけた場合は証拠を報告し、この担当では修正しない。

画像検索は文字列検索で、OCRや意味検索ではない。対象は資料一覧から追加された独立画像。Wikiだけに追加された画像の逆登録は含めない。
