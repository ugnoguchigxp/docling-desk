# Docling Azure OCR

Azure Document Intelligence Read adapter for Docling Desk and Docling.

Install from a checkout with `python -m pip install ./packages/docling-azure-ocr`.
The Docling plugin entry point is registered on installation. External OCR requires explicit configuration; no keys are bundled.

See [setup](../../docs/azure-ocr-setup.md). This package is MIT licensed; dependencies retain their own licenses.
