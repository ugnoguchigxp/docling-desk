# 原本閲覧の要求

版付き参照を検証して原本の閲覧先を取得する。

## 前提と引数の入手元

必要なactionはread。利用者とscopeは認証済み接続から確定する。検索・根拠の版と任意のlocationを渡す。PDFのpage・PPTXのslide・XLSXのsheet番号は1始まり。Word等のdocumentは1。embed_urlは資格情報を含まないが、開くだけでは認証されない。status=connection_requiredなら画面のコードを利用者から受け取りconnect_document_viewへ進む。

## 入出力と呼び出し経路

MCPの完全な入出力スキーマと、対応する文書HTTP操作はこのガイドのschemasに含まれる。section=schemasでも取得できる。HTTPのIf-MatchはMCPではetag、Idempotency-Keyはidempotency_key。既存文書ツールは業務引数をargumentsの中へ入れる。

ホストAPIはPOST /host/tools/request_document_viewに、信頼するホストの認証とuser_id・argumentsを送る。user_idをLLMから受け取って権限を決めない。ガイドGET APIの利用者別BearerとホストAPIの資格情報を混同しない。

## 副作用と結果の確認

文書の原本や索引を変更しない。説明・本文の取得成功は、外部処理の実行や書き込み成功を意味しない。閲覧コードの承認は短期の閲覧接続を作る。
