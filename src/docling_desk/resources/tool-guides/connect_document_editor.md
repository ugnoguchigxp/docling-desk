# 編集画面の接続

利用者が編集画面で確認した接続コードを承認する。

## 前提と引数の入手元

必要なactionはwrite。利用者とscopeは認証済み接続から確定する。write権限と利用者が提供した編集用コードが必要。閲覧セッションから編集権限を作らない。同じdraft_idを人とAIが編集できるが、古いetagの保存は拒否される。

## 入出力と呼び出し経路

MCPの完全な入出力スキーマと、対応する文書HTTP操作はこのガイドのschemasに含まれる。section=schemasでも取得できる。HTTPのIf-MatchはMCPではetag、Idempotency-Keyはidempotency_key。既存文書ツールは業務引数をargumentsの中へ入れる。

ホストAPIはPOST /host/tools/connect_document_editorに、信頼するホストの認証とuser_id・argumentsを送る。user_idをLLMから受け取って権限を決めない。ガイドGET APIの利用者別BearerとホストAPIの資格情報を混同しない。

## 副作用と結果の確認

この操作は保存または実行状態を変更する。対象と基準版を取得してから実行する。保存成功と検索反映を分けて確認する。
