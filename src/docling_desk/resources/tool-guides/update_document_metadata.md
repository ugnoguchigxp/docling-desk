# 文書管理情報の更新

title・language・保存先などの管理情報を更新する。

## 前提と引数の入手元

必要なactionはwrite。利用者とscopeは認証済み接続から確定する。最新source_etagをetagに指定。metadataの中へ包まず、title・collection_id等を直接渡す。frontmatterのtitleは自動変更しない。scope変更は変更前後のwrite権限が必要。更新後のetagを次の操作に使う。

## 入出力と呼び出し経路

MCPの完全な入出力スキーマと、対応する文書HTTP操作はこのガイドのschemasに含まれる。section=schemasでも取得できる。HTTPのIf-MatchはMCPではetag、Idempotency-Keyはidempotency_key。既存文書ツールは業務引数をargumentsの中へ入れる。

ホストAPIはPOST /host/tools/update_document_metadataに、信頼するホストの認証とuser_id・argumentsを送る。user_idをLLMから受け取って権限を決めない。ガイドGET APIの利用者別BearerとホストAPIの資格情報を混同しない。

## 副作用と結果の確認

この操作は保存または実行状態を変更する。対象と基準版を取得してから実行する。保存成功と検索反映を分けて確認する。
